# CompTIA Network+ N10-009 学習アプリ

Network+学習用のブラウザアプリです。

## 収録
- 500問
- 4択
- 分野表示
- 正解・不正解
- 解説
- 練習問題
- 模擬試験
- 間違えた問題の復習
- 成績のlocalStorage保存
- iPhone / PC対応

※問題はNetwork+学習用に作成したオリジナル問題です。CompTIA公式問題集の転載ではありません。

## GitHub Pages
1. GitHubで新しいリポジトリを作成
2. ZIPを展開し、5ファイルをアップロード
3. Settings → Pages
4. Deploy from a branch
5. Branch: `main` / `root`
6. Save
7. 表示されたURLをiPhoneのSafariで開く
